# AI Mini Search Engine

An AI-powered mini search engine built using Python, Flask, and TF-IDF algorithms for intelligent document retrieval and ranking.

---

## Features

- Keyword-based document search
- TF-IDF ranking algorithm
- Fast document retrieval
- Modern dark-themed UI
- Relevance score display
- Flask web application

---

## Tech Stack

- Python
- Flask
- Scikit-learn
- HTML
- CSS

---

## Installation

### Clone Repository

```bash
git clone https://github.com/mynkohli/AI-Mini-Search-Engine.git
```

### Install Dependencies

```bash
pip install flask
pip install scikit-learn
```

---

## Run Project

```bash
python app.py
```
